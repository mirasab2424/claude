# SMART WAY — сайт образовательного центра

Многостраничный сайт для **smart.is-best.net** на трёх языках: русский (`/`), казахский (`/kz/`),
английский (`/en/`). Главная, 6 страниц курсов (английский, IELTS, математика, НИШ, подготовка к школе,
продлёнка), преподаватели, цены, о центре, контакты. Админка — `/admin`.

## Как устроено

PHP 8.2+ и Twig, без базы данных для контента.

- `app/content/default.json` — **все факты** (контакты, филиалы, курсы, цены, преподаватели, FAQ),
  каждый текст в виде `{"ru": …, "kz": …, "en": …}`. Пустой перевод заменяется русским.
- `app/lang/{ru,kz,en}.php` — строки интерфейса: заголовки, кнопки, подписи (ключи одинаковые во всех трёх).
- `app/templates/site/*.twig` — страницы, `app/templates/admin/*.twig` — админка.
- `app/lib/` — `App` (маршруты, рендер, приём заявок), `Content` (default.json + правки),
  `Admin` и `Form` (редактор, построенный по структуре данных), `Leads` (заявки в SQLite), `Auth`.
- `public/` — корень сайта: `index.php`, `.htaccess`, стили, скрипт, шрифт Nunito, картинки.

```bash
composer install --working-dir=sites/smartway/app
php -S localhost:8300 -t sites/smartway/public sites/smartway/public/index.php   # http://localhost:8300
```

## Админка

`/admin`, один пароль. Хеш начального пароля — в `app/config.php`, после смены — в `app/storage/admin.json`.
5 неудачных попыток за 15 минут с одного IP блокируют вход.

- **Заявки**: форма «Пробный урок» сохраняет заявку на сайте, затем предлагает написать в WhatsApp.
  Статусы, заметки, выгрузка в CSV.
- **Содержимое**: контакты, филиалы, курсы, цены, преподаватели (с загрузкой фото), тексты главной —
  на трёх языках. Списки: добавить, удалить, поменять порядок.
- **Тексты интерфейса**: любая строка из `app/lang/*.php`.

Правки хранятся в `app/storage/content.json` (поверх `default.json`), заявки — в `app/storage/leads.sqlite`,
фото — в `public/uploads/`. Деплой эти файлы не трогает. Перед каждым сохранением кладётся резервная копия
в `app/storage/backups` (последние 30). «Вернуть исходное» в разделе удаляет правки и показывает `default.json`.

## Диагностика по математике (`/test`)

Бесплатный онлайн-тест для 5–11 классов на трёх языках — перенос Google-форм центра (RU и KZ), английский перевод наш.
Ученик выбирает класс, вводит имя и телефон родителя, отвечает и сразу видит процент, уровень, результат по темам и карту
ответов (правильные ответы не показываем — их разбирают на бесплатной консультации). Каждое прохождение создаёт заявку.

- Тесты и ключи ответов — `app/content/diagnostics.json` (вопрос: тема, баллы, текст `{ru,kz,en}`, ключ `check`).
  Ключи посчитаны вручную: в публичных формах их нет.
- Проверка — `app/lib/Diag/Checker.php` + `Expr.php`: понимает `1/4` и `0,25`, `5√2`, `x ≥ −4`, `(−∞;2)∪(3;+∞)`,
  выражения (`108x⁸y⁷` сравнивается с эталоном по значениям в нескольких точках), пары `(2;1);(−1;4)`, ключевые слова.
- Админка «Диагностика (тест)»: распределение результатов, динамика за 30 дней, средние по классам, карта тем (класс × тема),
  самые трудные задания с самым частым неверным ответом, конверсия в запись; у прохождения — ответы рядом с ключом
  и ручная правка балла («засчитать / ½ / 0»), статус заявки, WhatsApp с готовым текстом.
- При первом запуске добавляются 20 демо-прохождений (помечены «демо»), их можно удалить одной кнопкой.

## Тест по английскому (`/test/english`)

Пять вступительных тестов центра из Google-форм: 4–5 класс, 6–7 класс, 8–10 класс, Upper-Intermediate, Advanced
(40–50 заданий с выбором ответа, темы «Грамматика» и «Лексика»). Лежат в том же `diagnostics.json` с `"subject": "english"`,
кодами `grade` 104, 106, 108, 121, 131 и подписью `label`. Ключи посчитаны вручную (в формах их нет); в форме 6–7 класса
ответ был вписан в текст вопроса — заменён пропуском. Заявка: «Тест по английскому, {уровень} — N%».
На странице теста переключатель «Математика / Английский»; ссылки — на главной, на странице курса английского и в подвале.

## Выгрузка данных (`/admin/export`)

Бесплатный хостинг: чтобы данные не потерялись, в админке есть «⬇ Выгрузка данных» (`App\Export`, `lib/Export.php`).
Заявки и результаты тестов — Excel (.xlsx, свой писатель на ZipArchive), PDF (tFPDF + DejaVu Condensed, альбомный A4)
и CSV (UTF-8 с BOM, «;»). «Всё одним архивом» — ZIP: Excel на два листа, CSV, `data.json` (все заявки и прохождения
с ответами), копия `leads.sqlite` (`VACUUM INTO`), `storage/*.json` (правки админки, без `admin.json` и `throttle.json`)
и `uploads/`. Кнопки есть и на страницах «Заявки» и «Диагностика». Демо-прохождения в выгрузку не входят.

## Фото преподавателей

`public/img/teachers/*.jpg` — одна серия 600 × 800 на фоне в цветах сайта. Сейчас они сделаны из постов Instagram
(маленькие, макушки срезаны). Новые исходники обрабатываются скриптом `tools/teacher_photos.py`
(вырезка фона, одинаковый кадр, цвет, тень): `python sites/smartway/tools/teacher_photos.py исходники/*.jpg --out sites/smartway/public/img/teachers`.
Имена исходников — как в `default.json` (`isaev-nuradin.jpg` …). Нужен `pip install "rembg[cpu]" pillow`.

## Деплой

После пуша изменений в `sites/smartway/` GitHub Actions (`.github/workflows/deploy-smartway.yml`) ставит Twig
через composer, складывает `public/` и `app/` в `dist/` и заливает по FTP в `/smart.is-best.net/htdocs/`
(папка `app` закрыта `.htaccess`). Секреты `FTP_*` те же, что у трекера. Старые адреса `*.html`
перенаправляются на новые (301).
