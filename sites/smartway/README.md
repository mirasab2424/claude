# SMART WAY — сайт образовательного центра

Статический многостраничный сайт для **smart.is-best.net**: главная, 6 страниц курсов
(английский, IELTS, математика, НИШ, подготовка к школе, продлёнка), преподаватели, цены,
о центре, контакты.

## Как устроено

- `data.py` — **все факты**: контакты, филиалы, курсы, цены, преподаватели, FAQ.
  Цены и тексты меняются здесь.
- `templates/` — страницы (Jinja2). `base.html` — шапка, подвал, окно заявки;
  `_macros.html` — общие блоки (карточка цены, CTA, преподаватель).
- `static/` — стили, скрипт, шрифт Nunito (с казахскими буквами), картинки.
- `build.py` собирает всё в `dist/` и проверяет, что нет битых ссылок.

```bash
pip install jinja2
python3 sites/smartway/build.py
cd sites/smartway/dist && python3 -m http.server 8300   # http://localhost:8300
```

Заявки уходят в WhatsApp: форма собирает имя, класс, направление и филиал в готовое сообщение.
Сервер для форм не нужен.

## Деплой

После пуша изменений в `sites/smartway/` GitHub Actions (`.github/workflows/deploy-smartway.yml`)
собирает сайт и заливает по FTP в `/smart.is-best.net/htdocs/`. Используются те же секреты
`FTP_*`, что и для трекера: оба домена в одном аккаунте InfinityFree.

## Источники

- PDF-буклеты центра (новые данные): курсы, цены, НИШ, FAQ.
- Instagram @smartschool_ast: преподаватели, фото, второй филиал, «5+ лет».
