# SMART WAY — сайт образовательного центра

Многостраничный сайт для **smart.is-best.net** на трёх языках: русский (`/`), казахский (`/kz/`),
английский (`/en/`). Главная, 6 страниц курсов (английский, IELTS, математика, НИШ, подготовка к школе,
продлёнка), преподаватели, цены, о центре, контакты. Админка — `/admin`.

## Как устроено

PHP 8.2+ и Twig, без базы данных для контента.

- `app/content/default.json` — **все факты** (контакты, филиалы, курсы, цены, преподаватели, FAQ),
  каждый текст в виде `{"ru": …, "kz": …, "en": …}`. Пустой перевод заменяется русским.
- `app/lang/{ru,kz,en}.php` — строки интерфейса: заголовки, кнопки, подписи (ключи одинаковые во всех трёх).
- `app/templates/site/*.twig` — страницы, `app/templates/admin/*.twig` — админка.
- `app/lib/` — `App` (маршруты, рендер, приём заявок), `Content` (default.json + правки),
  `Admin` и `Form` (редактор, построенный по структуре данных), `Leads` (заявки в SQLite), `Auth`.
- `public/` — корень сайта: `index.php`, `.htaccess`, стили, скрипт, шрифт Nunito, картинки.

```bash
composer install --working-dir=sites/smartway/app
php -S localhost:8300 -t sites/smartway/public sites/smartway/public/index.php   # http://localhost:8300
```

## Админка

`/admin`, один пароль. Хеш начального пароля — в `app/config.php`, после смены — в `app/storage/admin.json`.
5 неудачных попыток за 15 минут с одного IP блокируют вход.

- **Заявки**: форма «Пробный урок» сохраняет заявку на сайте, затем предлагает написать в WhatsApp.
  Статусы, заметки, выгрузка в CSV.
- **Содержимое**: контакты, филиалы, курсы, цены, преподаватели (с загрузкой фото), тексты главной —
  на трёх языках. Списки: добавить, удалить, поменять порядок.
- **Тексты интерфейса**: любая строка из `app/lang/*.php`.

Правки хранятся в `app/storage/content.json` (поверх `default.json`), заявки — в `app/storage/leads.sqlite`,
фото — в `public/uploads/`. Деплой эти файлы не трогает. Перед каждым сохранением кладётся резервная копия
в `app/storage/backups` (последние 30). «Вернуть исходное» в разделе удаляет правки и показывает `default.json`.

## Деплой

После пуша изменений в `sites/smartway/` GitHub Actions (`.github/workflows/deploy-smartway.yml`) ставит Twig
через composer, складывает `public/` и `app/` в `dist/` и заливает по FTP в `/smart.is-best.net/htdocs/`
(папка `app` закрыта `.htaccess`). Секреты `FTP_*` те же, что у трекера. Старые адреса `*.html`
перенаправляются на новые (301).
