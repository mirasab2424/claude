# «Астана: парадные сцены» — правила для ИИ-агентов (Codex, Claude и другие)

Личный проект владельца репозитория, не публичный сайт. 3D-карта Астаны: весь город — прозрачные голубые
здания по контурам OpenStreetMap, цветом выделены концертные залы, куда ходят в классике, и личные места
(дома, работа, участок со стройкой). Владелец снимает в этих местах короткие видео и записывает с экрана
пролёты камеры между ними для переходов в роликах. Общаемся на русском.

## Как устроено
- Статическая страница без сборщика: `public/index.html` (разметка и стили) + `public/js/app.js` (сцена, места,
  камера, интерфейс) + `public/js/kit.js` (общие материалы и помощники) + `public/models/*.js` (модели зданий).
- Three.js **0.147.0**, глобальная сборка с CDN (`three.min.js` и `examples/js/controls/OrbitControls.js`, глобальный `THREE`).
  ES-модулей и `importmap` нет: последняя версия с глобальной сборкой — 0.147, не обновлять.
- Данные:
  - `public/data/city.json` — город: `b` (здания: высота + дельта-кодированный контур в 1/2 м), `roads`, `water`, `parks`,
    `river` (в метрах), `venues` и `lm` — контуры залов и ориентиров (`c` центр, `ang` угол длинной оси, `L`, `W`, `ring`).
    Координаты — метры от точки `origin` (51.1285, 71.4400): x на восток, y на север; в сцене `X = x`, `Z = −y`.
  - `public/data/places.json` — список общих мест: имя, подпись, цвета для тёмной и светлой темы, модель, камера при подлёте.
  - `public/data/places.private.json` — **личные места, в git не попадает** (см. «Личное»). Если файла нет, карта работает без них.
- Модель здания — `MODELS.<id> = function (THREE, ctx) { …; return group; }` в `public/models/<id>.js`.
  Группа строится в своих координатах: метры, Y вверх, начало — центр контура на земле, X — длинная ось.
  Страница сама ставит её на место. В `ctx`: `L`, `W`, `ring` (контур в координатах модели, `[x, y]`, в сцене `Z = −y`),
  `color`, материалы `solid(hex, emissive)`, `white`, `ghost`, `ghostLine`, `bm(тёмная, светлая)`, помощники
  `add(group, geo, mat, x, y, z)`, `edges(mesh, lineMat, angle)`, `extrude(group, ring, h, mat, y)`. Подробно — в `js/kit.js`.
- Темы: тёмная по умолчанию, светлая — кнопка «Светлая» / клавиша `T`. Материал, который должен меняться с темой, создаётся
  через `bm()` или `th()` из `kit.js`. Цветные модели залов одинаковы в обеих темах; светлые цвета — с низким `emissive`
  (около 0.12), иначе они выгорают в белое.
- Камера: `#vN` в адресе открывает место N, `0` — весь город, `Пробел` — тур по местам с `tour: true`, `H` — скрыть интерфейс
  для записи экрана, `S` — скрыть список, `L` — подписи, `V` — кадр 9:16.

## Личное
- Репозиторий **публичный**. Адреса, координаты участка, место работы и всё, что указывает на них, в git не кладём.
- Личные места задаются в `private/personal.json` (id здания в OpenStreetMap или углы участка) и собираются в
  `public/data/places.private.json`. Обе папки в `.gitignore`. Личные здания остаются в общей массе `city.json`, а в
  `places.private.json` лежат их номера (`hide`), чтобы страница спрятала их под цветной моделью.
- В коде, комментариях, коммитах и PR не писать адреса, названия ЖК, координаты и номера объектов OSM личных мест.
- Дом на участке строится по размерам проекта «Наш дом» (`sites/miras/public/data/measurements.json` и `design.json`).
  Там свои правила: числа не выдумывать, всё приблизительно.

## Что нельзя
- Ничего не выдумывать: адреса, высоты, названия и факты о зданиях — только из OpenStreetMap, официальных сайтов и фото.
  Если размер неизвестен — оценка по фото с пометкой в комментарии «примерно».
- Не повторять чужие 3D-модели и не тянуть их из интернета: модели процедурные, в коде.
- Внешних загрузок со стороны страницы, кроме Three.js с jsDelivr и шрифтов Google Fonts, нет (страница открывается как
  Artifact claude.ai, там действует CSP). Картинки — только `CanvasTexture`, нарисованные в коде.
- Не ломать запись экрана: интерфейс прячется по `H`, подписи по `L`, ничего не должно мигать или прыгать во время пролёта.

## Производительность
Карта — около 54 тыс. зданий одной геометрией, на слабом ноутбуке и телефоне уже на пределе.
- Модель одного здания: не больше ~25 тыс. треугольников и ~400 мешей. Повторы — `InstancedMesh` или общая геометрия.
- Общие материалы и геометрии, без теней, без новых источников света.
- Никаких `Math.random()` без зерна: модель должна выглядеть одинаково при каждом открытии.

## Данные города
- Сырые выгрузки Overpass лежат в `raw/` (≈70 МБ, в git не попадают). Скачать заново: `tools/fetch_osm.sh`.
- Пересобрать данные: `python3 tools/build_data.py` (пишет `city.json`, а при наличии `private/personal.json` — ещё и
  `places.private.json`). Без `raw/` пересборка невозможна — тогда `city.json` не трогать.

## Проверка
- `tools/get-libs.sh` — один раз, локальные копии Three.js для проверки без интернета.
- `NODE_PATH=$(npm root -g) node tools/shot.cjs` — снимки всей карты и каждого места в обеих темах в `shots/`,
  ошибки консоли — в выводе, при ошибках код выхода 1. `--no-private` — как увидит посторонний (без личных мест).
- `NODE_PATH=$(npm root -g) node tools/shot.cjs --model opera` — одна модель с четырёх сторон (`public/dev/model.html`),
  в выводе число треугольников и мешей. Удобно для работы над моделью: открыть картинку, поправить, повторить.
- Chromium и Playwright уже стоят в среде Claude Code; в другой среде: `npm i -g playwright && npx playwright install chromium`.
- Перед PR: `tools/shot.cjs` без ошибок, снимки посмотрены.

## Выкладка
Домена нет. Владелец смотрит карту как приватный Artifact на claude.ai. Публикует Claude Code: страница
`public/index.html`, рядом файлы `js/*.js`, `models/*.js`, `data/city.json`, `data/places.json` и, только у владельца,
`data/places.private.json`. Новый файл, который грузит страница, нужно добавить в этот список при публикации.
