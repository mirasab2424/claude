# Наш дом — miras.page.gd

Статический сайт о доме после перестройки: план этажа, размеры, окна, двери, электрика и трубы по комнатам, 3D.
Все размеры **примерные**: получены по видео, рулетки в кадре не было, масштаб — гипотеза «блок 600 × 300 мм».

## Данные — в одном месте

`public/data/measurements.json` — единственный источник чисел. План (`assets/plan.js`), таблицы (`plan.html`) и 3D
(`assets/view3d.js`) строятся из него в браузере. Когда появятся замеры рулеткой, замените файл — всё пересчитается.

Правила показа (см. `docs/HANDOFF.md`):
- округление: дом до 0,5 м, комнаты и проёмы до 0,1 м, всегда «≈» и погрешность;
- `estimated` — обычный вид, `assumed` — курсив с пунктиром и пометкой «предположение»,
  `observed_position_not_measured` — только списком по комнатам или числом на комнату;
- названия комнат описательные: назначение подтверждено только у санузла;
- лестница — только вариант с подписью «предварительно» и пометкой о возможном конфликте с дверью санузла D7.

Гараж: `public/garage/` — старая схема (вариант по генплану), оставлена по просьбе владельца.

`docs/` — передача данных, открытые вопросы и план, нарисованный при разборе видео (для справки, на сайте не используется).
Видео, кадры и `evidence/` в репозиторий не добавляются. Адреса, координат и личных данных на сайте нет.

## Локально

```bash
python3 -m http.server 8097 -d sites/miras/public   # http://localhost:8097
```

## Публикация

`.github/workflows/deploy-miras.yml` запускается вручную (Actions → Deploy miras.page.gd → Run workflow)
и заливает `public/` в `/htdocs/` (корневой сайт аккаунта InfinityFree).
