# Тесты Kostobe — kostobe.site.je

Сайт онлайн-тестов на трёх языках: русский (`/`), казахский (`/kz/`), английский (`/en/`).
Кабинет учителя — `/admin`.

## Для ученика

1. Выбирает тест на главной (тесты сгруппированы по предметам).
2. Вводит фамилию и имя, класс; предмет подставляется из теста.
3. Отвечает на вопросы. Есть таймер (если учитель задал время), счётчик ответов; черновик ответов
   хранится в браузере, поэтому случайная перезагрузка страницы ничего не теряет.
4. Сразу видит результат: процент, баллы, оценку по шкале, число верных ответов, время и разбор
   (правильные ответы и пояснения — если учитель их не скрыл).

## Виды заданий

| Вид | Как проверяется |
|---|---|
| Один ответ (A, B, C…) | верно / неверно |
| Несколько ответов | всё или ничего, либо частичный балл (за верный выбор плюс, за неверный минус) |
| Верно / неверно | верно / неверно |
| Ответ текстом | несколько допустимых ответов на каждом языке; регистр, ё/е, пробелы и точка в конце не важны |
| Ответ числом | с допустимой погрешностью и единицей измерения |
| Расставить по порядку | полный балл за точный порядок, иначе половина доли верных позиций |
| Найти пары | доля верных пар |

## Переводы

Каждый текст хранится как `{"ru", "kz", "en"}`. Варианты ответов, пункты и пары — общие для всех языков,
переводится только их текст, поэтому правильный ответ один на все языки. В редакторе переключатель
RU / KZ / EN; красная точка — есть непереведённые тексты. Если перевода нет, ученик видит текст на другом языке.
У теста отмечаются языки, на которых он доступен.

## Кабинет учителя

- **Тесты**: создание, редактирование, копия, удаление, публикация. Перемешивание вопросов и вариантов,
  ограничение времени, показ правильных ответов после теста.
- **Статистика**: фильтр по тесту, классу и ученику; средний процент и оценка, распределение оценок,
  средние по классам, доля баллов по каждому вопросу, разбор каждой попытки, выгрузка CSV для Excel.
- **Предметы**, **учителя** (учитель видит только свои тесты; администратор — всё), **настройки**
  (название сайта, шкала оценок: по умолчанию «5» от 85%, «4» от 65%, «3» от 40%).

Начальный вход: логин `admin`, пароль сообщён владельцу отдельно (в репозитории только хеш в `app/config.php`).

## Как устроено

PHP 8.2+, Twig, SQLite (`app/storage/tests.sqlite`, создаётся при первом запросе вместе с примерами тестов
из `app/content/samples.json`, генератор — `samples.py`). Правильные ответы в браузер не уходят: при старте
попытки снимок вопросов сохраняется в базе, проверка — на сервере.

- `app/lib/` — `App` (маршруты), `Site` (страницы ученика), `Admin` (кабинет), `Tests` (тесты и проверка
  данных из редактора), `Grader` (перемешивание, проверка, разбор), `Db`, `Auth`, `L` (тексты на трёх языках).
- `app/templates/site`, `app/templates/admin` — Twig. `app/lang/{ru,kz,en}.php` — строки интерфейса ученика.
- `public/` — корень сайта: `index.php`, стили, `js/take.js` (прохождение), `js/editor.js` (редактор вопросов).

```bash
composer install --working-dir=sites/kostobe/app
php -S localhost:8400 -t sites/kostobe/public sites/kostobe/public/index.php
```

Деплой: пуш в `sites/kostobe/` → `.github/workflows/deploy-kostobe.yml` → FTP в `/kostobe.site.je/htdocs/`.
